# Author payout bank details

The earnings page includes a bank form at `/author/earnings#payout-bank`. Owner-only GET/PUT `/author/bank-details` use private/no-store responses. PUT accepts exactly the three bank fields and the displayed account version, trims text, rejects blank/control-character inputs and preserves leading zeros in account numbers.

Saving rechecks the active Author role and credentials, serializes with account suspension/deletion and monthly evaluation, and appends an audit digest in the same transaction. Stale versions return 409; an audit failure rolls the entire update back. Private bank fields stay excluded from normal account serialization.

The saved bank is used for future evaluations. Existing withdrawal/payout bank snapshots are not rewritten. There is no manual withdrawal request or automatic transfer. Missing-bank notifications link to the form; created/Paid/Failed notifications link to earnings instead of the reader top-up wallet. Notification URLs are generated by the server and never copied from payload links; transient email addresses remain private.

Validation covers access control, stale writes, rollback, private serialization, bank snapshot immutability, financial notification links, form save/error/reload behavior and the existing earnings page. No backend schema changes; media/AI remain deferred. Browser visual acceptance remains separate.
